# Cinema Seat Booking System

A simple cinema seat booking system built with **Next.js and React**. Users can select a movie, choose available seats, enter their booking details, and confirm their booking.

## Features

* Movie selection
* Interactive cinema seat layout
* Available and booked seat states
* Seat selection and booking
* Booking details form
* Booking confirmation cards
* Responsive design
* Toast notifications
* Context API for managing booking and seat state

## Tech Stack

* Next.js
* React.js
* JavaScript
* Tailwind CSS
* Context API

## How to Run

Clone the repository:

```bash
git clone https://github.com/dawoodahmed7711/cinema-seat-booking-system.git
```

Go to the project folder:

```bash
cd cinema-seat-booking-system
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Project Purpose

I built this project to practice working with React state, Context API, dynamic data, forms, and seat-booking logic in a Next.js application.
